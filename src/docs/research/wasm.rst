WebAssembly experiments
=======================

A WebAssembly or browser-hosted Workbench is research, not a supported runtime. The
current product depends on native Qt 6.8 widgets, QRhi, Slang runtime integration, and
native resource lifetime.

A useful experiment would first identify replaceable boundaries—document model,
compiler availability, presentation, and backend policy—rather than claiming that a
wheel or generated shader target implies browser support.
