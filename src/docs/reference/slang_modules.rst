Slang module reference
======================

``miskeyed.ui``
   UI metadata attribute declarations.
``miskeyed.time``
   Host-managed time, delta, frame, and frame-rate fields.
``miskeyed.viewport_camera``
   Host camera contract for viewport scene programs.
``miskeyed.render_toy``
   Scene/Post pass contract and scene texture consumption.
``miskeyed.shader_toy``
   Minimal fullscreen consumer contract.

Sources live under ``shaders/workbench/`` and are packaged with installed builds.
