Use ShaderToy
=============

.. image:: ../images/shader_toy.png
   :alt: Focused ShaderToy fullscreen QRhi viewport in the shared Workbench shell
   :align: center

ShaderToy binds one document to a fullscreen QRhi consumer. It reuses the workspace,
Inspector, and time context. It is intentionally a minimal authoring loop, not a full
clone of the Shadertoy website.

Switching to it changes the visible primary layout; Render Toy's session remains alive.
