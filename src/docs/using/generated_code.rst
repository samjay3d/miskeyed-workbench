Inspect generated code
======================

.. image:: ../images/source_generated_compare.png
   :alt: Focused Compare editor with authored Slang and generated HLSL side by side
   :align: center

1. Focus the document you want to inspect.
2. Choose **Generated** for one output or **Compare** for source beside output.
3. Choose HLSL, GLSL, SPIR-V, or Metal from **Target**.
4. Read this as compiler output, not as the active runtime backend.

Running Vulkan while inspecting HLSL is valid. See
:doc:`../concepts/entry_points` and :doc:`../reference/backends`.
