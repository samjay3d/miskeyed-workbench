Use the workspace
=================

The workspace shows open Slang documents. Selecting a tab focuses that document for
editing and inspection; it does not silently rebind a viewport.

.. image:: ../images/workspace_documents.png
   :alt: Focused Workbench workspace editor showing open document tabs
   :align: center

To work with a document:

1. Open it or choose its tab.
2. Edit Source, Generated, or Compare view.
3. Click a viewport to focus the document bound to that consumer.
4. Read the status binding summary before changing a tool binding.

See :doc:`../concepts/documents_and_bindings` for the open/focused/bound model.
