Resources and generated code
============================

Slang reflection reports textures, samplers, buffers, parameter blocks, bindings,
and spaces. The Resources Inspector presents that compiler knowledge; the renderer
uses it to build native bindings.

Generated targets are read-only compiler products for HLSL, GLSL, SPIR-V, and Metal.
Selecting one changes the editor view only. It does not select the live QRhi backend.
