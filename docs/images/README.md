# Images

Screenshots and diagrams used by the top-level `README.md`.

## workbench.png

The hero screenshot shown at the top of the project README: the Workbench window with
a live Slang shader on the left, the rendered viewport(s), and the compiled HLSL output
on the right.

To add/update it, save the screenshot as `workbench.png` in this folder (this exact
path is what the README links to). A width around 1200–1600 px looks best on GitHub.
