# Images

Screenshots and diagrams used by the top-level `README.md`.

## workbench.png

The hero screenshot shown at the top of the project README: the Workbench window with
a live Slang shader, rendered viewports, reflected controls, inspectable Workbench
headers, and compiled output.

Windows CI captures the current window into this exact path and uploads it as the
`workbench-documentation` artifact. A maintainer can promote the reviewed artifact into
the repository; CI deliberately does not push binary changes into contributor branches.
A width around 1200–1600 px looks best on GitHub.
