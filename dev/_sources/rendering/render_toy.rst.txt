Render Toy
==========

Render Toy demonstrates an explicit two-pass consumer. Its session binds one open
document to **Scene** and another to **Post**, plus selected vertex/fragment entry
points for each. The scene pass renders to an offscreen color texture; the post pass
samples that texture and presents the graded result.

::

   shared TimeContext -> Scene document/entries -> offscreen scene texture
                                              -> Post document/entries -> output

The workspace owns both documents and time. ``RenderToySession`` owns bindings and
entry selections. ``RenderPass``/``SlangRhiWidget`` own GPU state. Focusing the Post
document does not change either binding; switching to the Shader Toy layout does
not destroy this session.

See ``modes/render_toy/RenderToySession.*`` and the corresponding tool adapter in
``WorkbenchToolFactory.cpp``.
