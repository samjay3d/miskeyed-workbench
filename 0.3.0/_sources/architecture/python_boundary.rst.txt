Python and Shiboken boundary
============================

Shiboken exposes the same native QObject/QWidget types to PySide6. Python may compose
or embed those objects; it does not own a second compiler, dependency graph, or render
core.

The installed module is ``miskeyed.workbench``. Native lifetime, signals, resource
creation, synchronization, and QRhi submission remain C++ responsibilities.

--------------

Relevant source: ``bindings/typesystem_workbench.xml`` and
