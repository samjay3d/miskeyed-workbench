Evaluation and time
===================

Overview
--------

Time is an evaluation sample, not the timeline widget.

Mental model
------------

::

   coordinate + rate -> seconds
   playback range    -> descriptive domain
   transport         -> seek/play/loop policy
   timeline          -> user interface

A floating-point coordinate supports subframes. Rate states units per second.
Repeated evaluation at the same coordinate still has a new evaluation index.

Workbench sends samples to active consumers and updates host-managed Slang uniforms
without recompilation. See :doc:`../workbench_slang/time` and
:doc:`../architecture/time`.
